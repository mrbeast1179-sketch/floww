# Quarantined Models — DO NOT LOAD

## Synthetic data models (original quarantine)
These models were trained on synthetic data generated by `np.random.normal`.
They output degenerate predictions (single class at ~0.9998 confidence).

**Reason for quarantine:** Trained on 187 after-hours snapshots with constant spot.
No real market data was used. Any inference from these models is meaningless.

## SPY_direction_v1.0 — Quarantined 2026-05-18
**Reason:** 167 samples / 45 features = 3.7 samples per feature (severe overfit).
Sharpe 31.5 is deeply implausible for daily direction prediction.
Backtest_2024.md shows in-sample fit (all months at 1.000 precision/recall).
**Path forward:** Retrain as v2.0 with Databento GEX features + proper 60/20/20 splits.

## TLT_direction_v1.0 — Quarantined 2026-05-18
**Reason:** Sharpe 0.00 means literally no edge over baseline.
Shipped due to broken SHIP-gate bug (beats_baselines hardcoded True).
**Path forward:** Investigate feature engineering for TLT specifically.

## Audit principles (from multiticker_model_audit.md §9)
- **In-sample = useless.** Train/test must never overlap.
- **Baseline-beat is the floor.** Must beat majority + persistence + logistic.
- **Sharpe > 5 daily** = suspect by default.
- **Empty baselines dict** = unverified model. SHIP gate defaults False.
- **Class balance reporting** required for every training run.
