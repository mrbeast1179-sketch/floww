## Terminal conditions

An agent stops only when its admitted unit is committed and pushed, is blocked
with a reproducible reason and exact next command, or no safe task card exists.
Low credits are a checkpoint condition, never permission to overclaim, force
push, weaken tests, or leave an undocumented dirty tree.

## Standing execution boundary

Floww is paper/replay/research only. No live order, paid data call, credential
rotation, deployment, or external Discord/broker witness is authorized by these
prompts. Mocked tests are not venue proof. A paper order is not a fill. A model
score is not alpha until point-in-time, costed, out-of-sample evidence exists.
