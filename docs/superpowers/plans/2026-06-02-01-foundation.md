# AlphaPod Clone — Plan 01: Foundation (Design System + Shell) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. This is the **Foundation lane (DeepSeek Pro)** — it must complete and its tokens must be frozen before per-tab lanes (Plans 03+) start.

**Goal:** Give floww AlphaPod's app shell — a 240px collapsible left rail and a consolidated, gold-accented, white-alpha design-token system with Inter/Space Grotesk — while Trinity + Heatseeker render unchanged.

**Architecture:** One global `:root` token layer re-valued to AlphaPod (existing floww variable names keep their names, gain AlphaPod values; new `--gold`/`--conf-*`/`--surface-*` names added). Trinity + Heatseeker wrap in a `.legacy-theme` scope that re-declares floww's original token values, so the global re-hue cannot touch them. A new `<AppShell>` renders the rail and wraps App.js's existing `page===` switch (App.js edits stay surgical).

**Tech Stack:** React 19, CRA + craco, Tailwind 3 (utilities only — shadcn token utilities stay unused), `@testing-library/react` + `craco test` (jest), `lucide-react` icons. **CSS is mocked in jest** (`craco.config.js` maps `\.(css)$` → `identity-obj-proxy`), so token/visual correctness is verified by screenshot diff, not unit tests; component *behavior* is unit-tested normally.

- [ ] **Step 4: Implement `Sidebar.jsx`**

```jsx
// frontend/src/shell/Sidebar.jsx
import { useState, useEffect } from "react";
import { PanelLeftClose, PanelLeft } from "lucide-react";
import { NAV_ITEMS, SIDEBAR_KEY } from "./navConfig";

export default function Sidebar({ page, onNavigate }) {
  const [collapsed, setCollapsed] = useState(() => localStorage.getItem(SIDEBAR_KEY) === "true");
  useEffect(() => {
    localStorage.setItem(SIDEBAR_KEY, String(collapsed));
    document.documentElement.setAttribute("data-sidebar-collapsed", String(collapsed));
  }, [collapsed]);

  return (
    <aside
      data-collapsed={collapsed}
      className="apw-rail"
      style={{ width: collapsed ? 64 : 240, background: "var(--bg-sidebar)",
               borderRight: "1px solid var(--border)", transition: "width 180ms",
               height: "100vh", position: "sticky", top: 0, flexShrink: 0,
               display: "flex", flexDirection: "column" }}
    >
      <div style={{ display: "flex", alignItems: "center", justifyContent: "space-between", padding: "12px" }}>
        {!collapsed && <span style={{ fontFamily: "var(--font-display)", fontWeight: 700 }}>floww</span>}
        <button aria-label={collapsed ? "expand sidebar" : "collapse sidebar"}
                onClick={() => setCollapsed(c => !c)}
                style={{ background: "transparent", border: 0, color: "var(--text-dim)", cursor: "pointer" }}>
          {collapsed ? <PanelLeft size={18} /> : <PanelLeftClose size={18} />}
        </button>
      </div>
      <nav style={{ display: "flex", flexDirection: "column", gap: 2, padding: "4px 8px" }}>
        {NAV_ITEMS.map(item => {
          const active = page === item.id;
          return (
            <button key={item.id} onClick={() => onNavigate(item.id)}
              aria-current={active ? "page" : undefined}
              title={item.label}
              style={{ display: "flex", alignItems: "center", gap: 10, padding: "8px 10px",
                       borderRadius: 8, border: "1px solid transparent", cursor: "pointer",
                       fontSize: 13, textAlign: "left",
                       color: active ? "var(--gold)" : "var(--text-dim)",
                       background: active ? "var(--gold-dim)" : "transparent",
                       borderColor: active ? "var(--gold-border)" : "transparent" }}>
              <span style={{ width: 18, textAlign: "center" }}>{item.label[0]}</span>
              {!collapsed && <span>{item.label}</span>}
            </button>
          );
        })}
      </nav>
    </aside>
  );
}
```
