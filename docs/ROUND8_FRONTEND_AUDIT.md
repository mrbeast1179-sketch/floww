## 1. Missing `key` props in `.map()` calls

Scan: `grep -rnE "\.map\(\(" frontend/src/components/ --include="*.jsx" | grep -v "key="`

**Total potential instances: ~70** (after filtering same-line `key=`)

Many are false positives (data-processing maps or keys on subsequent lines).
The following files have the most `.map()` calls without inline `key=`:

- **PortfolioPanel.jsx**: spotScenarios, volScenarios, hedge_positions maps
- **VannaChart.jsx**: strikes.map for data processing (likely safe)
- **SocialFlowPanel.jsx**: flow_signals.slice.map
- **heatseeker/NodeLifecyclePanel.jsx**: nodes.map
- **heatseeker/RainbowRoadIndicator.jsx**: Array.from.map

**Recommendation**: Round 9 should audit the top ~5 files for runtime React key warnings and add proper keys to JSX-rendered maps.
